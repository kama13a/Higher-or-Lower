# Higher Lower Game

A Python implementation of the classic "Higher Lower" game where players guess which celebrity has more Instagram followers.

## Project Overview
This project was built as part of my Python learning journey. The goal was to practice:
- Breaking down a large problem into smaller, solvable pieces
- Writing clean, organized code using functions
- Working with real data in a list of dictionaries

## What I Learned
- Problem decomposition
- Function design (`format_data()`, `check_answer()`)
- Game logic with while loops
- Working with lists of dictionaries
